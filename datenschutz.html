🔒 Datenschutzerklärung

Zuletzt aktualisiert: April 2025 — ipwho.am / MarkysMarks
TL;DR — Kurz & klar Wir erfassen keine personenbezogenen Daten. Kein Login, keine Cookies, kein E-Mail-Tracking, kein Fingerprinting. Deine IP-Adresse wird ausschließlich zur Anzeige auf deinem eigenen Bildschirm verwendet — und nicht von uns gespeichert.

1. Verantwortlicher

Diese Website (ipwho.am) wird betrieben von MarkysMarks. Kontakt über GitHub Issues.

3. Externe Dienste (Drittanbieter)

ipapi.co
Zur Geo-Lokalisierung deiner IP-Adresse wird eine Anfrage an ipapi.co gestellt. Dabei wird deine IP-Adresse kurzzeitig an deren Server übertragen. ipapi.co speichert laut eigener Aussage keine personenbezogenen Daten dauerhaft. Datenschutzerklärung: ipapi.co/privacy

CounterAPI (counterapi.dev)
Zur Anzeige anonymer Seitenaufrufzahlen nutzen wir CounterAPI. Es wird ausschließlich ein Zähler inkrementiert — ohne IP-Adresse, ohne User-Agent, ohne Cookies. Reine Zahl, keine Nutzeridentifikation möglich.

Google Fonts
Die Schriftart JetBrains Mono wird über Google Fonts CDN geladen. Dabei wird deine IP-Adresse an Google-Server übertragen. Datenschutzerklärung: policies.google.com/privacy
Alternativ kannst du Google Fonts in deinem Browser blockieren — die Seite fällt dann auf System-Monospace zurück.

GitHub Pages
Diese Website wird auf GitHub Pages (Microsoft) gehostet. GitHub kann dabei laut eigener Datenschutzrichtlinie technische Zugriffsdaten (IP, User-Agent) in Server-Logs speichern. Datenschutzerklärung: GitHub Privacy

4. Cookies & Tracking

Diese Website setzt keine Cookies. Es wird kein Cross-Site-Tracking, kein Werbe-Tracking und kein Fingerprinting eingesetzt. Der anonyme Seitenaufrufzähler (CounterAPI) funktioniert ohne Cookies und ohne Nutzererkennung.

5. Deine Rechte (DSGVO)

Da wir keine personenbezogenen Daten verarbeiten oder speichern, sind folgende DSGVO-Rechte nur eingeschränkt anwendbar:

Recht auf Auskunft (Art. 15) · Recht auf Löschung (Art. 17) · Recht auf Datenübertragbarkeit (Art. 20) — Es gibt bei uns schlicht keine personenbezogenen Daten, die wir herausgeben oder löschen könnten.

Für Daten bei Drittanbietern (ipapi.co, Google, GitHub) wende dich direkt an diese.

6. Open Source

Der vollständige Quellcode dieser Website ist öffentlich einsehbar auf github.com/MarkysMarks/ipwho.am. Jede Zeile Code kann geprüft werden. Kein verstecktes Tracking, keine verschleierte Logik.

7. Änderungen

Diese Datenschutzerklärung kann bei Bedarf aktualisiert werden. Das Datum der letzten Änderung ist oben vermerkt. Änderungen sind im Git-Verlauf nachvollziehbar.
