FAQ
Wie erzwinge ich IPv4 oder IPv6?▶
Nutze curl -4 ipwho.am für IPv4 oder curl -6 ipwho.am für IPv6. Die meisten Clients entscheiden automatisch basierend auf deiner Netzwerkkonfiguration.
Kann ich JSON erzwingen?▶
Ja, sende den Header Accept: application/json oder füge .json an die URL an. Beispiel: curl ipwho.am/json
Ist automatisierte Nutzung erlaubt?▶
Ja, solange das Rate-Limit respektiert wird. Bitte auf max. 1 Anfrage/Minute bei automatisierten Abfragen beschränken. Anfragen über dem Limit erhalten Status 429.
Wie prüfe ich eine fremde IP-Adresse?▶
Einfach die IP an den Pfad anhängen: curl ipwho.am/8.8.8.8/json — gibt alle verfügbaren Informationen zur angegebenen Adresse zurück.
Woher stammen die Geodaten?▶
Die Standortdaten basieren auf der GeoLite2 Datenbank von MaxMind, ergänzt durch verschiedene ASN-Datenquellen. Geodaten sind Schätzungen und können ungenau sein.
