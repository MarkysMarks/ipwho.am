Datenschutz & Privatsphäre
Was wird gespeichert?
Wir speichern keine personenbezogenen Daten. Kein Logging von IP-Adressen, keine Cookies, keine Tracking-Pixel. Einzig ein anonymer Seitenaufruf-Zähler (via CounterAPI) wird inkrementiert — ohne IP oder Nutzerdaten.
Externe Dienste
Geo-Daten werden von ipapi.co abgefragt. Deine IP wird dabei kurzzeitig an deren Server übertragen und unterliegt deren Datenschutzrichtlinie. Fonts: Google Fonts (JetBrains Mono).
Hosting & Open Source
Diese Seite wird auf GitHub Pages gehostet. Der vollständige Quellcode ist öffentlich auf GitHub einsehbar. Keine serverseitige Logik, kein Backend.
Deine Rechte
Da wir keinerlei personenbezogene Daten erfassen, gibt es nichts zu löschen oder anzufordern. Fragen? GitHub Issues oder direkt im Repository.
Vollständige Datenschutzerklärung: datenschutz.html
FAQ
Wie erzwinge ich IPv4 oder IPv6?▶
Nutze curl -4 ipwho.am für IPv4 oder curl -6 ipwho.am für IPv6.
Kann ich JSON erzwingen?▶
Ja, sende den Header Accept: application/json oder nutze curl ipwho.am/json
Ist automatisierte Nutzung erlaubt?▶
Ja, max. 1 Anfrage/Minute bei automatisierten Abfragen. Anfragen über dem Limit erhalten Status 429.
Wie prüfe ich eine fremde IP-Adresse?▶
Einfach die IP anhängen: curl ipwho.am/8.8.8.8/json
Werden meine Daten gespeichert?▶
Nein. Kein Logging, keine Cookies, keine personenbezogenen Daten. Nur ein anonymer Seitenbesuchszähler. Mehr Details unter Datenschutz.
